# AISummary

为 Typecho 文章提供 `ai_summary` 自定义字段，并在文章编辑页提供摘要编辑框和“生成摘要”按钮。生成时会把编辑器中的标题、正文以及正文引用的图片一起发送给 OpenAI 格式的聊天补全接口。

## 功能

- 摘要保存在自定义字段 `ai_summary` 中，主题可通过 `$this->fields->ai_summary` 读取。
- 文章编辑页的自定义字段区域提供摘要编辑框，支持手动编辑和字数统计。
- “生成摘要”按钮直接读取编辑器中的当前内容（包括尚未保存的修改），生成后填入摘要框；仍需正常保存/发布文章才会写入数据库。
- 支持 OpenAI 兼容的多模态消息：文字作为 `text` 片段，图片作为 `image_url` 片段。
- 从 Markdown 行内图片、引用式图片和 HTML `<img>` 中提取图片地址。
- 本站图片会读取本地文件并转换为 base64 data URL，避免外部接口无法访问 `127.0.0.1`；外站图片直接把 URL 交给接口抓取。
- 图片过多或过大时会按设置截断、压缩或跳过，并在生成结果中提示。
- 开启“正文前显示摘要”后，会在文章正文顶部输出 `<aside class="ai-summary">`，可自定义标题或关闭。
- 博客列表、置顶/热门文章等使用 `excerpt` 的位置会优先显示 `ai_summary`，没有摘要时回退到原正文摘要。

## 安装

1. 确认 PHP 已启用 `cURL` 扩展（必需）。图片压缩需要 `GD` 扩展，未启用时超限图片会被跳过。
2. 将 `AISummary` 目录放到 `usr/plugins/`。
3. 在后台“控制台 → 插件”中启用 AISummary，并填写接口设置。

如果此前已经启用过旧版本，修改 hook 注册列表后需要先在后台禁用、再重新启用插件，新的前台输出钩子才会生效。

## 设置

| 设置 | 说明 |
| --- | --- |
| API 地址 | OpenAI 格式接口的根地址（如 `https://api.openai.com/v1`），也可直接填写完整的 `/chat/completions` 地址 |
| API Key | 以 `Authorization: Bearer <key>` 发送；保存时留空会保留已有密钥 |
| 模型名称 | 需要支持图片输入的模型，例如 `gpt-4o-mini`、`qwen-vl-plus`、`glm-4v` 等 |
| 系统提示词 | 约束摘要语言、风格和长度 |
| 接口温度 | 留空时不发送 `temperature`，用于兼容限制该参数的模型 |
| 请求超时 | 等待接口返回的秒数，图片较多时建议调大 |
| 发送图片 | 关闭后只发送标题和正文 |
| 最多发送图片数 | 按正文出现顺序取前 N 张 |
| 正文最大字符数 | 超出后截断，`0` 表示不截断 |
| 图片最长边 | 超过该尺寸的图片压缩到该边长 |
| 单张图片最大体积 | 超过后尝试压缩，仍超限则跳过 |
| 正文前显示摘要 | 开启后，有摘要的文章会在正文顶部显示摘要 |
| 摘要标题 | 显示在摘要上方的标题，留空则只显示摘要正文 |

## 主题中使用

插件默认已经在文章正文前输出摘要。如果需要自定义位置或样式，也可以在主题中读取字段自行输出：

```php
<?php if (!empty($this->fields->ai_summary)): ?>
    <p class="post-summary"><?php echo htmlspecialchars($this->fields->ai_summary, ENT_QUOTES, 'UTF-8'); ?></p>
<?php endif; ?>
```

正文前摘要的默认样式在 `assets/aisummary-front.css`，前台 HTML 页面都会加载。这样主题开启 PJAX 时，即使用户先停留在列表页、再换入文章内容，摘要样式也不会缺失。文章存在 `ai_summary` 时，`excerpt` 会返回摘要纯文本，因此列表卡片和 meta description 也会使用摘要；没有摘要时保持原来的正文摘要。

## 已知限制

- 图片压缩依赖 GD；超大图片（超过 1600 万像素）会被跳过。
- 图片以 data URL 发送时请求体会明显变大，可通过“最多发送图片数”和“图片最长边”控制。
- 生成结果由第三方模型返回，保存前请自行检查。
- AIContentSummaryPlus 也使用 `ai_summary` 字段，两个插件不要同时启用；启用 AISummary 时会检测并拒绝。
- 识别正文中的 Markdown 行内图片 `![alt](url)`、引用式图片 `![alt][id]` / `![alt][]` / `![alt]`，以及 HTML `<img src="...">`。
